# 바다를 읽는 인공지능 · 부산 해양 데이터 과학 디지털 교과서

고등학교 「데이터 과학」 연계 디지털 교과서입니다. 부산 바다의 문제 10가지를 데이터 분석 6단계로 해결합니다.

- 교과서 4단원·프로젝트 10개, 브라우저에서 바로 실행하는 파이썬 실습실
- 형성평가, 데이터 자료실(CSV·노트북), 결과보고서 제출
- 교사: 학습 모니터링(로그인·로그아웃 기록, 점수), 보고서 AI 평가(영역별 점수와 종합 평가 의견 초안, 교사 검토 후 확정)

이 저장소는 **GitHub Pages**로 열리는 웹앱입니다. 회원·학습 기록은 선생님의 **구글 시트**에 저장됩니다(구글 Apps Script 연결).
연결 방법은 [설치안내.md](설치안내.md)를 보세요. 연결 전에는 '미리보기 모드'로 화면만 둘러볼 수 있습니다.

모든 실습 데이터와 수치는 수업용으로 만든 가상 데이터입니다.
